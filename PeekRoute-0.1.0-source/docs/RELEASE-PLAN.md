# План выпуска Linklet

Зафиксировано 2026-09-06.

## Репозитории

- `https://github.com/alybo/Linklet-dev` — приватная разработка, исходники, совместная работа, тесты и релизные теги. Локальный origin указывает сюда.
- `https://github.com/alybo/Linklet` — публичная страница продукта и распространение выпусков. Публикуемые файлы готовятся отдельно от истории разработки.

## Предлагаемый процесс

1. Разработчик проверяет изменения и фиксирует релизный тег в Linklet-dev.
2. Компаньон собирает этот тег, подписывает Developer ID Application, выполняет notarization и stapling. Сертификаты остаются у подписывающего.
3. Разработчик получает финальный архив, проверяет его и подписывает архив ключом Sparkle.
4. Готовый выпуск публикуется в GitHub Releases публичного Linklet.
5. После проверки скачивания публикуется appcast.xml; приложение получает обновление через Sparkle.

## Следующие шаги

- Решено: публиковать исходники Linklet под GPL-3.0-only в публичном Linklet. К каждому бинарному выпуску предоставлять соответствующие исходники и необходимые зависимости; см. RELEASING.md в корне.
- До первого публичного выпуска согласовать постоянный bundle identifier, команду Apple Developer и владельца ключа Sparkle с резервной копией.
- Подготовить публичную страницу с описанием, системными требованиями, скачиванием, историей версий и сведениями о лицензиях.
- Выбрать постоянный HTTPS-адрес appcast.xml. GitHub Pages публичного репозитория — предложенный вариант; пока не настроен.
- Интегрировать Sparkle: открытый ключ, адрес ленты, проверку обновлений и настройки автоматического обновления. Закрытый ключ не хранить в Git.
- Подготовить команды упаковки и генерации appcast, проверку подписей и инструкцию выпуска для компаньона.
- Проверить установку и обновление между двумя подписанными сборками перед публичным запуском.

На момент записи Sparkle, сайт и автоматическая публикация не настроены.
