# Скачивание файлов: локальная проверка

29 октября 2026. Изменения остаются локально; GitHub, версии и релизы не меняются.

## Поведение

- Ссылки с `download`, ответы с `Content-Disposition: attachment` и форматы, которые WebKit не отображает, переходят в нативный `WKDownload`. Запрос не повторяется через URLSession: сохраняются POST, cookies, редиректы и контекст страницы. Внутренние blob/data поддержаны для скачивания; входящие ссылки для предпросмотра по-прежнему только HTTP(S).
- Системный диалог сохранения предлагает имя файла и папку «Загрузки». Имя и папку можно изменить; замена существующего файла подтверждается штатным NSSavePanel. Несколько диалогов показываются по очереди.
- Раздел «Загрузки» добавлен в конец боковой панели без сброса её прежнего порядка. Одна строка на файл: имя, значок состояния, тонкий прогресс и отмена. Размеры соответствуют остальным пунктам. Статус, объём и ошибка доступны при наведении и в контекстном меню. Завершённый файл по клику или команде «Показать в Finder» показывается в Finder. Автоматического открытия файлов нет.
- Меню Linklet → «Загрузки» открывает и прокручивает боковую панель к списку, даже если открытие панели у края экрана выключено. Саму настройку это не включает. Завершённые, отменённые и неудачные записи можно очистить кнопкой в заголовке; файлы при этом остаются на диске.
- Закрытие исходной страницы, окна сайта или всех веб-окон не отменяет начатое скачивание. Общий менеджер удерживает WKDownload; приватные cookies удерживаются отдельной временной арендой до завершения последней связанной страницы/загрузки, затем очищаются. Это не включает постоянное хранение данных сайтов.
- При обычном выходе с активными загрузками Linklet предлагает продолжить или выйти и остановить их. Перед завершением процесса обрабатываются callbacks отмены, заканчивается уже начатый перенос готового файла и убираются временные файлы. Принудительное завершение процесса и восстановление после сбоя этим этапом не покрываются.

## Сохранение файлов

Данные сначала скачиваются в отдельную папку в системном временном каталоге. После успеха файл копируется в скрытый промежуточный файл рядом с назначением и публикуется перемещением/заменой. Чтение, копирование, сравнение файлов и очистка выполняются вне MainActor. Отмена и сбой сети сохраняют старый файл. Если назначение появилось или изменилось после выбора, операция завершается ошибкой вместо перезаписи нового содержимого.

При переносе сохраняется quarantine-метка WebKit; если её нет, добавляется стандартная метка веб-загрузки macOS с именем Linklet. При замене используются метаданные нового файла. API: [WKDownload](https://developer.apple.com/documentation/webkit/wkdownload), [условия выбора назначения](https://developer.apple.com/documentation/webkit/wkdownloaddelegate/download(_:decidedestinationusing:suggestedfilename:completionhandler:)), [quarantineProperties](https://developer.apple.com/documentation/foundation/urlresourcevalues/quarantineproperties).

Список хранится только в памяти текущего запуска. Возобновление после выхода, повторный запуск ошибочного POST, автоматическое открытие файла и отправка файлов на сайты не добавлены. Следующий отдельный этап — file input/NSOpenPanel.

## Автоматические проверки

Команда проекта:

```sh
xcodebuild -project Linklet/Linklet.xcodeproj -scheme Linklet -sdk macosx test CODE_SIGNING_ALLOWED=NO
```

Покрыты реальные загрузки WKWebView с локального HTTP-сервера: отображаемый MIME с attachment, HTML download, авторизованный POST ровно одним запросом, blob, data, окно сайта, параллельные загрузки, отмена выбора и передачи, обрыв сети, закрытие приватной страницы во время загрузки, удержание/очистка cookies, остановка для выхода. Отдельно проверены публикация/замена файла, сохранность старого содержимого, конфликт назначения, очистка промежуточного файла, quarantine и безопасное предлагаемое имя. Настоящий NSSavePanel проверен на предлагаемое имя и отмену после закрытия страницы.

Итог: **108 тестов, 0 ошибок**. Проверяется доступность списка при выключенной панели и сохранение её настроек. Снимок: `/tmp/linklet-downloads-sidebar.png`. Финальный лог: `/tmp/linklet-downloads-verified-tests.log`.

Реальные пользовательские аккаунты, Finder, внешние диски, подпись/нотаризация и сайты, требующие отдельного диалога HTTP Basic Auth, этим прогоном не проверяются. HTTP authentication challenges используют стандартную обработку WebKit; TLS-проверки не обходятся.

## Сборка и ручная проверка

Тестовая копия: `build/WindowPreview/Linklet.app`, с прежним bundle ID `Linklet`. Перед заменой завершить установленный Linklet; это сохраняет прежний домен настроек. Копия не запускается поверх пользовательского сеанса автоматически.

1. Скачать документ или архив, изменить имя/папку и проверить содержимое.
2. Скачать экспорт из личного кабинета и файл, создаваемый сайтом через JavaScript.
3. Начать большую загрузку, закрыть исходную страницу и проверить завершение в меню Linklet → «Загрузки».
4. Начать две загрузки, отменить одну; вторая должна продолжаться. Проверить отмену системного диалога сохранения.
5. Сохранить поверх тестового существующего файла: старая версия сохраняется до успеха скачивания. Отмена или обрыв не должны её менять.
6. Проверить «Показать в Finder», очистку записей и предупреждение при выходе с активной загрузкой.

Чужие untracked-файлы, существовавшие до задачи, не включаются в коммит.
