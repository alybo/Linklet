# Закладки и копирование из адресной плашки

30 октября 2026. Локальная сборка без изменения версии и публикации.

## Поведение

- Иконка `bookmark.fill` показывает, что текущий полный URL сохранён. Если закладки нет, используется прежняя контурная `bookmark`. Изменения общего списка закладок сразу отражаются во всех открытых окнах. Состояние не зависит от видимости sidebar или избранного в быстром поиске.
- Сопоставляется адрес страницы, включая путь, query и fragment. Другие страницы того же домена не считаются сохранёнными. При сравнении нормализуются регистр схемы/хоста, пустой корневой путь и стандартный HTTP(S)-порт.
- Нажатие на сохранённую закладку открывает её редактирование вместо попытки создать дубликат.
- Иконка ссылки и домен находятся в одной плашке с общим фоном. Нативная кнопка иконки слева копирует полный текущий адрес левой или правой кнопкой мыши (также Control-кликом), включая query и fragment. Редактор не раскрывается, навигация и фокус страницы не меняются.
- При копировании только иконка меняется на галочку на две секунды с переходом прозрачности. Домен постоянно виден; отдельного текста уведомления и места для него нет. Ширина плашки при смене иконки не меняется. Повторный клик перезапускает таймер. Новый адрес или раскрытие редактора отменяют подтверждение.
- Клик по домену раскрывает редактор; правый/Control-клик по домену также раскрывает его, вместо прежнего копирования. ⌘L работает как раньше. Зоны нажатия не пересекаются.
- В раскрытом редакторе поле имеет естественную высоту одной строки и центрируется внутри плашки. Текст и живой field editor с курсором выровнены по вертикальному центру. Иконка скрывается, доступная ширина отдаётся адресу.
- В раскрытом редакторе остаётся обычное контекстное меню текста. Для VoiceOver есть отдельная кнопка/действие копирования и объявление результата. Reduce Motion отключает переход иконок.

## Проверка

```sh
xcodebuild -project Linklet/Linklet.xcodeproj -scheme Linklet -sdk macosx test CODE_SIGNING_ALLOWED=NO
```

**129 тестов, 0 ошибок**. Лог: `/tmp/linklet-address-pill-full-tests.log`. App и распакованная копия ZIP прошли `codesign --verify --deep --strict`. Минимальная поддерживаемая macOS отдельно не проверялась.

Интеграционный тест проверяет реальную AX-кнопку закладки в основном и дочернем окнах, обновление после сохранения/удаления, редактирование без дубликата, настоящие события правого/Control/левого клика по иконке, полный адрес в pasteboard, постоянно видимый домен, фиксированную геометрию, повторный таймер, отмену подтверждения при смене URL и сохранность живой страницы. Отдельно проверены клик по домену и вертикальное положение поля и живого field editor. Исходное содержимое pasteboard восстанавливается после теста.

## Проверка владельцем

1. Полностью завершить Linklet и запустить новую сборку.
2. Открыть сохранённую ссылку: иконка закрашена. Сохранить новую страницу и удалить закладку через sidebar: состояние сразу меняется.
3. Нажать левой, затем правой кнопкой на иконку ссылки и вставить результат в текстовое поле: скопирован полный открытый URL. Две секунды вместо иконки видна галочка, домен остаётся на месте. Проверить также google.com и более короткий домен.
4. Повторить копирование до исчезновения галочки, затем кликнуть по домену и проверить ⌘L. В раскрытом редакторе проверить положение текста/курсора и стандартное контекстное меню.
5. Повторить в окне, открытом сайтом, на длинном адресе и при светлом/тёмном оформлении.
