# Тестовый стеклянный вид боковой панели

29 октября 2026. Локальная сборка; публикация и версия приложения не меняются.

## Выбор вида

Настройки → Боковая панель → Вид боковой панели:

- **Чёрный** — прежний вариант, остаётся значением по умолчанию для существующих и новых профилей.
- **Стекло (тест)** — чёрная левая часть с переходом к прозрачному нативному Liquid Glass справа.

Меняется только фон. Используются тот же `SidebarContour`, размеры, плечи у края экрана, строки, иконки, отступы, обработчик изменения ширины и анимация открытия/закрытия. Оформление веб-окон не затронуто. Выбор хранится отдельно в `sidebarAppearance`; остальные настройки, порядок разделов и закладки не сбрасываются. Переключение применяется к уже созданной панели; повторный запуск не нужен.

## Нативная реализация

Используется публичный SwiftUI `glassEffect(.clear, in: SidebarContour)` на macOS 26+. В старом варианте применяется `Glass.identity`, не рисующий стекло. Содержимое и материал обрезаются исходным контуром. Чёрная заливка — обычный градиент внутри нативной поверхности: слева она непрозрачна, после 58% ширины начинает плавно исчезать и у правой границы становится прозрачной. Градиент привязан к текущей видимой ширине при раскрытии.

Преломление, размытие и световые эффекты рисует macOS. Нет изображения фона, самостоятельно захваченного экрана, собственного blur/shader или обращения к private API для этого оформления. Синий оттенок на проверочной сцене возникает из-за синего фона; он не задан в рабочем оформлении. Интенсивность и вид стекла зависят от фона и версии системы и могут отличаться от iOS-референса.

Материал доступен только на macOS 26+. На macOS 14/15 остаётся чёрный вариант и пояснение в настройках; минимальная версия приложения не повышается. При «Уменьшении прозрачности» используется непрозрачный чёрный фон, даже если выбран тестовый вариант. Сам выбор при этом не стирается; системная настройка не меняется приложением.

Документация Apple:

- [Applying Liquid Glass to custom views](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views) — публичный модификатор, формы и материал.
- [glassEffect(_:in:)](https://developer.apple.com/documentation/swiftui/view/glasseffect(_:in:)) — применение эффекта к своей форме.
- [Glass.clear](https://developer.apple.com/documentation/swiftui/glass/clear), [Glass.identity](https://developer.apple.com/documentation/swiftui/glass/identity).
- [Build an AppKit app with the new design, WWDC25](https://developer.apple.com/videos/play/wwdc2025/310/) — нативные стеклянные контейнеры и рекомендации по размещению содержимого.

## Проверка

Обязательный полный прогон:

```sh
xcodebuild -project Linklet/Linklet.xcodeproj -scheme Linklet -sdk macosx test CODE_SIGNING_ALLOWED=NO
```

Новые проверки покрывают чёрный вид по умолчанию, сохранение выбора и существующих настроек, неизвестное значение настройки, реальный NSSegmentedControl в настройках, переключение уже созданной панели без изменения размера, рендер непрозрачных вариантов и fallback для Reduce Transparency. Прежние проверки геометрии и анимации выполняются вместе с ними.

Оптическая часть Liquid Glass отдельно проверена на экранном снимке системного композитора с контролируемым синим полосатым фоном: левая часть чёрная, правая пропускает фон, внешний контур соответствует прежнему. Обычный `NSView.cacheDisplay` возвращает промежуточную карту преломления вместо итогового стекла; автоматические проверки цветов применяются только к непрозрачным вариантам. Это ограничение снимка, а не изображение, используемое приложением.

Полный прогон: **112 тестов, 0 ошибок**. Лог: `/tmp/linklet-sidebar-glass-final-tests.log`. Снимки непрозрачных вариантов: `/tmp/linklet-sidebar-black.png`, `/tmp/linklet-sidebar-glass-reduced.png`. Ветка старых macOS защищена availability-проверками; фактический запуск сделан на текущей системе, а fallback дополнительно проверен явным входным значением Reduce Transparency.

В прогоне остаётся прежнее предупреждение SwiftUI о публикации состояния в тесте списка загрузок. Оно есть и в логе предыдущей сборки `/tmp/linklet-image-context-menu-tests.log`; новый переключатель вида этого предупреждения не выдаёт.

## Что проверить владельцу

1. После замены сборки убедиться, что панель по-прежнему чёрная.
2. Выбрать «Стекло (тест)» в настройках и открыть панель над разными окнами/обоями. Проверить чёрный левый край и прозрачный правый.
3. Изменить ширину, открыть/закрыть панель, переключиться между мониторами: контур и анимация должны оставаться прежними.
4. Проверить читаемость длинных названий, прокрутку, контекстные меню, изменение ширины и редактор закладок.
5. Вернуть «Чёрный»: прежний фон должен восстановиться. После перезапуска выбранный вид сохраняется.

Тестовая копия: `build/WindowPreview/Linklet.app`, bundle ID `Linklet`. Перед заменой полностью завершить установленный Linklet. Сборка для владельца не запускается автоматически поверх его текущей сессии.
