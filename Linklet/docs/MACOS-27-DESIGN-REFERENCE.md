# macOS 27: источник компоновки Linklet 1.7 (27)

Использован официальный **Apple macOS 27 UI Kit**, опубликованный в
[Apple Design Resources](https://developer.apple.com/design/resources/#macos):

- [Sketch](https://www.sketch.com/s/57153a31-3379-4737-8ac6-dbfd6525f052)
- [Figma](https://www.figma.com/community/file/1651309434229735362/macos-27)

Для сверки скачана публичная Sketch-версия и прочитаны реальные размеры слоёв.
Это дизайн-эталон; приложение использует системные AppKit, SwiftUI и SF Symbols.
Сам кит и его графические ресурсы в приложение не встраиваются.

Версия приложения Sketch, указанная в архиве: `2026.3.1`.
SHA-256 проверенного архива:
`f5aa2f4f319eae66b5eab0bbc0faacb10ce16656457cff528f9810d57ff1354d`.

## Изменения

Сохранены выбранные владельцем пять разделов, раскрытые параметры браузеров,
отдельный экран данных сайтов и отсутствие поиска/кнопок истории в настройках.
Большие дублирующие заголовок окна карточки убраны. Вместо независимых ручных
отступов используются системная Form и измеренные параметры кита.

Папки основной панели всегда используют контурный SF Symbol `folder` с весом
`regular` — легче среднего веса из кита по просьбе владельца. Размер символа
равен размеру текста, а не ширине ячейки. Центрирование внутри прежней ячейки
визуально сдвигает рисунок вправо, сохраняя колонку подписей. Раскрытие отражается
стрелкой; залитый массивный вариант больше не появляется.

Регрессия рендерит папки в трёх размерах и проверяет границы рисунка, его центр
и долю заполнения, чтобы исключить выступание влево и возврат залитого силуэта.
Снимки настроек и панели получены из нативных окон тестовой сборки.
