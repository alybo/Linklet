# Аудит настроек Linklet 1.7 — сборка 26

Проверены подвисания при выборе разделов, загрузка данных сайтов, жизненный цикл
окна настроек и изменение размера значка строки меню. Работа остаётся локальной.

## Найденные причины и исправления

| Проблема | Причина в сборке 25 | Исправление |
| --- | --- | --- |
| Вход в приватность запускает тяжёлый экран | Общая форма запускала `SiteDataService.refresh()` и строила строки всех сайтов | На главном экране остался переход «Данные сайтов». Загрузка и ленивый список находятся только на отдельном экране |
| Повторные загрузки после быстрых переходов | Отменённая SwiftUI-задача не отменяла уже запущенную сериализованную операцию WebKit; новые запросы добавлялись в очередь | Одновременные запросы обновления объединяются. Запрос из уже отменённой задачи не начинает работу |
| Повторная обработка дат для каждой строки | `lastVisit` фильтровал всю историю доменов при каждом вызове | Индекс последних посещений строится один раз и инвалидируется после изменений; поиск даты — по ключу |
| Задержка при показе окна настроек | `viewDidAppear` синхронно сканировал приложения и каталоги профилей браузеров | Этот вызов удалён. В настройках обнаружение браузеров работает асинхронно, только на экране поиска и браузеров или по кнопке обновления; повторные запросы объединяются |
| Скрытые окна и сохранённые деревья интерфейса | Чтение `hasOpenWindows` обращалось к ленивому контроллеру настроек и создавало его. Закрытое окно оставалось у модели вместе с интерфейсом и подписками | Чтение состояния не создаёт окно. Контроллер создаётся при открытии и освобождается после закрытия |
| Увеличенный значок строки меню | При переходе на AppKit размер SVG 14×14 был принудительно заменён на 18×18 | Используется исходный размер ресурса 14×14; сам SVG не менялся |

Сортировка имён записей WebKit перенесена в фоновую задачу. Сами объекты WebKit
остаются на MainActor. Изменения режима хранения и удаление по-прежнему выполняются
последовательно; подтверждение удаления сохранено.

## Упрощения интерфейса

- Удалены поиск по настройкам, история переходов и кнопки назад/вперёд.
- Разделы поиска и браузеров всегда раскрыты и разделены заголовками.
- «Данные сайтов» открываются внутри правой области. Текстовый переход
  «Приватность» возвращает к общим параметрам, без истории навигации.
- Основные разделы имеют собственную идентичность содержимого, чтобы формы
  разных разделов не переиспользовали состояние прокрутки друг друга.

## Проверки и пределы аудита

Регрессии проверяют отсутствие запросов WebKit при переключении общих разделов,
загрузку только отдельного экрана, объединение параллельных запросов, отзывчивость
MainActor при задержанном обнаружении браузеров, инвалидирование индекса дат,
освобождение содержимого закрытого окна и исходный размер значка. Снимки интерфейса
получены из настоящего `SettingsWindowController` в светлой и тёмной темах.

Тесты используют изолированные данные WebKit. Замер времени на реальном большом
хранилище владельца не выполнялся: устранены подтверждённые пути лишней работы,
а окончательная проверка ощущения скорости остаётся за владельцем.

Полный прогон сборки 26: 162 теста без ошибок. После финальной корректировки
отступов отдельно пройдены снимки интерфейса и проверка освобождения/восстановления
окна. Полные журналы находятся в `build/Linklet-1.7-validation/1.7-26/`.
