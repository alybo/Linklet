# Приветствие — концепция MVP

Заголовок: **Сначала посмотрите, затем откройте в своём браузере.**

Подзаголовок: **Быстро просматривайте ссылки и выбирайте, в каком браузере продолжить.**

Иллюстрация: `welcome-preview.png`. Панель настоящего окна Linklet, внутри демонстрационная страница. Это концепт, а не реализованное приветствие.

Страница: «Меньше вкладок. Больше фокуса.»

Описание: «Посмотрите страницу здесь. Продолжите в своём браузере, когда понадобится.»

Основное действие: «Настроить открытие ссылок».
Вторичное действие: «Сначала попробовать».
Пояснение перед настройкой: «Чтобы ссылки открывались в Linklet, выберите его браузером по умолчанию».

Приватность остаётся отдельной возможностью, не подзаголовком: предпросмотр не использует браузерную сессию; данные очищаются при завершении приложения, а не при закрытии окна.

## Визуальные материалы

Созданы встроенным ImageGen. Иконка: утверждённая версия с увеличенной адресной строкой и значком ссылки; удалён внешний чёрный фон для alpha. Менюбар: исходная SVG-геометрия пользователя, прозрачный вырез глаза, template rendering.

Промпт превью: сохранить панель и геометрию предоставленного скриншота, сменить заголовок на Linklet, заменить Example Domain минималистичной страницей с указанным русским текстом, светлым фоном и синим орбитальным мотивом с глазом.
