# Linklet 1.7 — локальная разработка

Версия: 1.7, текущая рабочая сборка: 23. Основа: подготовленная 1.6 (`9b4b4a8`).

По указанию владельца от 1 ноября 2026 года всё собирается локально. Не отправлять
коммиты, ветки, теги, Assets или appcast на GitHub без новой команды владельца.

## Согласованный состав

- Нативные настройки SwiftUI/AppKit в стиле системных настроек macOS:
  «Основные», «Окна и панель», «Поиск и браузеры», «Приватность», «О Linklet».
- Системные материалы и элементы управления, цветные иконки разделов,
  изменение размера окна, сохранение существующих предпочтений.
- Полные русский и английский интерфейсы, автоматический системный язык.
- «Режим окон»: «Одно окно» / «Несколько окон».
- «Поведение окна»: «Оставлять открытым» / «Скрывать» / «Поверх других окон»,
  с пояснением «При переключении между приложениями».
- Браузер для основной кнопки передачи ссылок выбирается явно и независимо от
  частоты использования; передаётся исходный HTTP(S)-адрес.
- Закладки редактируются в боковой панели; история и блокировщик — в приватности.
- Первое знакомство: приветствие, учебное окно с настоящим контролом адреса и
  выделенными целями/стрелками, необязательные настройки, финал с открытием
  быстрого поиска и настроек. Учебный пример работает без сети и не меняет историю.
- Входящая ссылка имеет приоритет над знакомством и сразу открывается с текущим
  выбором хранения данных. По умолчанию данные временные; сохранение включается
  только явным выбором пользователя.
- После закрытия страницы из раздела «Открытые» боковая панель остаётся открытой.
- Стрелки разделов/папок, плюс закладки и крестики открытых окон должны читаться
  на прозрачной части панели: белые символы с лёгкой тенью.

- Меню строки меню разделено на действия и настройки/справку. Встроенный выбор
  поведения окна убран; все предпочтения доступны в окне настроек.
- Исправлены платёжные окна, создаваемые через `window.open("", "_blank")`:
  WebKit передаёт пустой URL, который ранее отклонялся. Сайт получает рабочую
  ссылку на окно и может перенаправить его на страницу провайдера после ответа
  сервера. Входящие ссылки по-прежнему ограничены HTTP(S).

## Проверки

- Полный `xcodebuild ... test CODE_SIGNING_ALLOWED=NO`: 153 теста, без ошибок.
  В первом прогоне сборки 23 был таймаут активации адресной строки в старом тесте
  длинного OAuth-адреса; отдельная проверка и повторный полный прогон прошли.
- Проверены сохранение размера, миграция старых разделов, переключение языка без
  переоткрытия окна, явный выбор браузера и приватное открытие первой ссылки.
- Интеграционная проверка закрытия страницы через реальный крестик в панели
  подтверждает сохранение панели и оставшегося дочернего окна. Отдельно проверено
  закрытие последней страницы: панель остаётся открытой.
- Баг оплаты воспроизведён на открытой странице HIP Hosting: Arc открывал
  страницу ЮKassa, Linklet оставался на подготовке платежа. Оплата не выполнялась.
  Локальный тест повторяет вызов пустого окна из кода сайта, отложенный переход,
  обмен сообщениями и закрытие. До исправления сайт получал `null`; после —
  рабочее окно. Проверка обновлённой сборки на реальном аккаунте остаётся владельцу.
- Получены снимки пяти разделов настроек (светлый/тёмный вид) и четырёх экранов
  знакомства (русский/английский). При первоначальном просмотре настроек инструмент
  управления приложением завершился по таймауту; позднее диагностика оплаты через
  открытые приложения Linklet и Arc была доступна.
