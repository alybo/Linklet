# Linklet 1.7 — черновик для подписи

Версия: 1.7, текущая рабочая сборка: 31. Основа: подготовленная 1.6 (`9b4b4a8`).

1 ноября 2026 года владелец разрешил загрузить 1.7 на GitHub как черновик
для подписи другом с его Apple Developer аккаунта. Исходники и signing kit можно
отправить; публичный выпуск и обновление appcast выполняет издатель после
подписи, нотарификации и preflight с флагом `--owner-validated`. Подробности: `SIGNING-HANDOFF-1.7.md`.

## Согласованный состав

- Нативные настройки SwiftUI/AppKit в стиле системных настроек macOS:
  «Основные», «Окна и панель», «Поиск и браузеры», «Приватность», «О Linklet».
- Системные материалы и элементы управления, цветные иконки разделов,
  изменение размера окна, сохранение существующих предпочтений.
- Каркас настроек — нативный `NSSplitViewController`: постоянная боковая колонка
  без поиска и кнопок назад/вперёд, заголовок справа от разделителя.
  Ширина содержимого ограничена; формы и строки сверены с официальным
  Apple macOS 27 UI Kit. Повторяющие заголовок окна крупные карточки убраны.
  Убраны кнопка сворачивания колонки и заголовок над её левой частью. Светлая и
  тёмная темы, цвет выделения — системный акцент.
- Полные русский и английский интерфейсы, автоматический системный язык.
- Размеры строк и иконок колонки настроек следуют системному размеру бокового меню:
  24/32/40 pt для строк, 16/20/24 pt для ячеек иконок. Колонка — 256 pt.
- Папки основной панели вписаны в квадрат значка сайта (24×24 pt при крупном
  размере панели). Папка нарисована двумя слоями: при
  раскрытии передняя створка наклоняется, задняя слегка отклоняется. Нижний
  правый край задней стенки сужается внутрь и скрывается за непрозрачной
  передней створкой, без выступающего уголка. Заголовки разделов
  сдвинуты на 8 pt влево; ссылки и папки сохраняют общую колонку, вложенные ссылки
  имеют дополнительный отступ 16 pt относительно папки. Заголовок Linklet также сдвинут на 8 pt влево.
  Разделы и папки раскрываются/сворачиваются с изменением высоты и прозрачности
  за 0,26 с, стрелки поворачиваются. При Reduce Motion переход мгновенный.
  Это уточнение владельца поверх размеров кита.
- Поиск и браузеры: все разделы раскрыты, параметры разделены заголовками.
- Приватность: данные сайтов открываются отдельным переходом внутри окна.
  Общий экран не загружает записи WebKit; управление данными использует ленивый
  список. Повторные обновления объединяются, сортировка выполняется в фоне.
- Сканирование браузеров в настройках выполняется в фоне только в соответствующем
  разделе. Чтение статуса окон не создаёт настройки, закрытое дерево освобождается.
- Значок строки меню по уточнению владельца использует размер 16×16 pt.
  Результаты технической проверки — `SETTINGS-AUDIT-1.7.md`.
- «Режим окон»: «Одно окно» / «Несколько окон».
- «Поведение окна»: «Оставлять открытым» / «Скрывать» / «Поверх других окон»,
  с пояснением «При переключении между приложениями».
- Браузер для основной кнопки передачи ссылок выбирается явно и независимо от
  частоты использования; передаётся исходный HTTP(S)-адрес.
- Закладки редактируются в боковой панели; история и блокировщик — в приватности.
- Первое знакомство: приветствие, учебное окно с настоящим контролом адреса и
  выделенными целями/стрелками, необязательные настройки, финал с открытием
  быстрого поиска и настроек. Учебный пример работает без сети и не меняет историю.
- Входящая ссылка имеет приоритет над знакомством и сразу открывается с текущим
  выбором хранения данных. По умолчанию данные временные; сохранение включается
  только явным выбором пользователя.
- После закрытия страницы из раздела «Открытые» боковая панель остаётся открытой.
- При ручном открытии панели (меню, горячая клавиша, загрузки) автоскрытие по
  положению курсора начинается после первого наведения на панель. До этого панель
  остаётся открытой; Escape, повторное переключение и потеря фокуса закрывают её.
  Открытие наведением на край экрана сохраняет прежнее автоскрытие.
- Стрелки разделов/папок, плюс закладки и крестики открытых окон должны читаться
  на прозрачной части панели: белые символы с лёгкой тенью.

- Нативное меню `NSStatusItem`/`NSMenu`: быстрый поиск с назначенным сочетанием,
  HTTP(S)-ссылка из буфера, боковая панель, открытые окна с отметкой текущего,
  загрузки со счётчиком, настройки и подменю справки. Буфер читается только при
  открытии меню; ссылка передаётся обычному обработчику входящих ссылок.
  Справка объединяет знакомство, сведения о приложении и проверку обновлений.
  Найденное обновление выводится отдельным пунктом рядом с настройками.
  Предпочтения поведения окон остаются в окне настроек.
- Исправлены платёжные окна, создаваемые через `window.open("", "_blank")`:
  WebKit передаёт пустой URL, который ранее отклонялся. Сайт получает рабочую
  ссылку на окно и может перенаправить его на страницу провайдера после ответа
  сервера. Входящие ссылки по-прежнему ограничены HTTP(S).

## Проверки

- Сборка 31: только `xcodebuild ... build CODE_SIGNING_ALLOWED=NO`; по прямой
  просьбе владельца тесты не запускались. Предыдущая сборка 27: полный
  `xcodebuild ... test CODE_SIGNING_ALLOWED=NO`, 163 теста без ошибок.
  UI-тест длинного OAuth-адреса ожидает фактическую активацию окна перед нажатием
  на адресную строку. Нативные UI-тесты активируют окна и требуют отсутствия
  параллельного ручного ввода с клавиатуры.
- Проверены сохранение размера, миграция старых разделов, переключение языка без
  переоткрытия окна, явный выбор браузера и приватное открытие первой ссылки.
- Интеграционная проверка закрытия страницы через реальный крестик в панели
  подтверждает сохранение панели и оставшегося дочернего окна. Отдельно проверено
  закрытие последней страницы: панель остаётся открытой.
- Регрессионный тест ручного открытия проверяет ожидание курсора дольше 30 секунд,
  последующее автоскрытие и открытие загрузок; отдельно сохраняется проверка
  потери фокуса и открытия наведением на край экрана.
- Проверены отсутствие поиска и кнопок истории, выравнивание
  заголовка с правой колонкой, размер окна, обновление пунктов меню и активация
  существующего окна без перезагрузки. Снимки настроек делаются в настоящем
  `SettingsWindowController`, включая рамку и системную панель инструментов.
- Баг оплаты воспроизведён на открытой странице HIP Hosting: Arc открывал
  страницу ЮKassa, Linklet оставался на подготовке платежа. Оплата не выполнялась.
  Локальный тест повторяет вызов пустого окна из кода сайта, отложенный переход,
  обмен сообщениями и закрытие. До исправления сайт получал `null`; после —
  рабочее окно. Проверка обновлённой сборки на реальном аккаунте остаётся владельцу.
- Получены снимки пяти разделов настроек (светлый/тёмный вид) и четырёх экранов
  знакомства (русский/английский). При первоначальном просмотре настроек инструмент
  управления приложением завершился по таймауту; позднее диагностика оплаты через
  открытые приложения Linklet и Arc была доступна.

## Далее

Передача издателю через Draft Release 1.7. Владелец подтвердил ручную проверку: всё работает, повторные тесты не нужны.
Подпись, нотарификация и публичная
публикация здесь не выполняются. Архив Release универсальный, без Developer ID;
издатель выполняет preflight с `--owner-validated` и штатную публикацию на своём Mac. Тег `v1.7`
создаётся издателем на финальном коммите перед preflight; черновик привязан
к точному коммиту через target_commitish.

Локальная сборка для проверки: `build/Linklet.app`. Снимки интерфейса —
`build/Linklet-1.7-validation/1.7-27/`. Эти результаты игнорируются Git. Тестовый плагин
XCTest исключён из копии приложения; исходная тестовая сборка не изменялась.
