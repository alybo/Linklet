# Linklet 1.4.3

## Русский

- Очистка данных сайтов больше не задерживает открытие предпросмотра: в приватном режиме она запускается после закрытия последнего окна, а в режиме сохранения данных выполняется в фоне по расписанию.
- При каждом открытии быстрого поиска список избранного возвращается к началу.
- Убрано пустое системное окно автозаполнения, которое кратко появлялось под строкой поиска. Стеклянный вид панели сохранён.

Требуется macOS 14 или новее. Приложение поддерживает Apple Silicon и Intel.

## English

- Website data cleanup no longer delays opening a preview: private data is cleared after the last preview closes, while saved data is maintained on a background schedule.
- The favorites list returns to its starting position each time Quick Search opens.
- Prevented an empty system autofill window from briefly appearing below the search field. The glass panel appearance is unchanged.

Requires macOS 14 or later. Supports Apple Silicon and Intel.
