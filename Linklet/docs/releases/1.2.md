# Linklet 1.2

## Русский

### Что нового

- **Настройки по разделам.** «Основные», «Браузеры», «Данные сайтов» и «О программе» в одном окне с боковой навигацией. Linklet запоминает последний открытый раздел.
- **Сохранение данных сайтов.** Можно сохранять вход в аккаунты и настройки сайтов между открытиями Linklet. Данные хранятся на этом Mac отдельно от других браузеров. При первом открытии ссылки приложение объясняет оба режима и позволяет сразу перейти к настройкам.
- **Управление сохранёнными данными.** Просматривайте список сайтов, удаляйте данные отдельного сайта или всех сайтов сразу. Можно включить удаление данных сайтов, которые не посещались 7, 30 или 90 дней.
- **Ручной приоритет браузеров.** Перетаскивайте браузеры в настройках, когда сортировка по частоте использования выключена. Первый включённый браузер используется для основной кнопки открытия. Ручной порядок сохраняется при переключении режимов сортировки.
- **Раздел «О программе».** Версия приложения, сведения о разработчике, ссылки на Telegram и окно благодарности с копированием адреса.

### Что изменилось

- По умолчанию данные сайтов теперь очищаются при **закрытии или скрытии окна просмотра**, включая переключение в другое приложение в режиме «Скрывать». Для сохранения авторизации включите «Сохранять данные сайтов».
- Выключение сохранения требует подтверждения и удаляет ранее сохранённые данные. Ручное удаление также завершает текущий сеанс просмотра.
- Автоматическая очистка учитывает посещения сайтов; фоновые запросы не продлевают срок хранения. Очистка выполняется перед следующим просмотром.
- Начиная с 1.2 Linklet автоматически проверяет обновления, а **скачивание и установка требуют подтверждения**. Сохранённое отключение проверки обновлений учитывается.
- Переходим на номера версий из двух частей: **1.2**, затем 1.3, 1.4 и далее.

### Обновление с 0.1.1

После публикации подписанного выпуска и обновления ленты Sparkle версия 0.1.1 сможет получить 1.2 через встроенное обновление. Сам переход выполняется по настройкам, сохранённым в 0.1.1; новый порядок подтверждения действует после установки 1.2.

Требуется macOS 14 или новее. Сохранение данных не отменяет ограничения отдельных сайтов на вход во встроенном браузере.

## English

### New

- **Settings organized into four pages:** General, Browsers, Website Data, and About. Linklet remembers the last selected page.
- **Optional website data persistence.** Keep website sign-ins and preferences between previews, stored on this Mac separately from other browsers. A first-link introduction explains both modes and links directly to settings.
- **Website data controls.** View stored websites, delete one site's data or all data, and remove data for sites not visited for 7, 30, or 90 days.
- **Manual browser priority.** Drag browsers to reorder them when usage sorting is off. The first enabled browser is the primary opening action. Manual order is preserved when switching sorting modes.
- **About page** with the app version, developer information, Telegram links, and a support sheet with address copying.

### Changed

- Website data is cleared by default when the preview **closes or hides**, including switching apps in Hide mode. Enable Save Website Data to retain sign-ins.
- Turning saving off asks for confirmation and deletes stored data. Manual deletion also ends the current preview session.
- Inactivity cleanup counts website visits, not background requests, and runs before the next preview.
- Starting with 1.2, automatic checks remain available, while **downloads and installation require confirmation**. An existing preference to disable automatic checks is respected.
- Public version numbers now use two components: **1.2**, followed by 1.3, 1.4, and so on.

### Updating from 0.1.1

Once the signed release and Sparkle feed are published, 0.1.1 can update to 1.2 through the built-in updater. The transition follows the preferences saved in 0.1.1; the new confirmation policy takes effect after 1.2 is installed.

Requires macOS 14 or later. Website persistence does not bypass restrictions on signing in through embedded browsers.
