Linklet 1.3

  • Быстрый поиск. Компактная полупрозрачная строка открывается по настраиваемой горячей клавише без ожидания выделения или буфера обмена.
  • Раздел «Поиск» в настройках. Выбор горячей клавиши и основного поисковика: Google, Яндекс, DuckDuckGo или Bing.
  • Выбор поисковика для одного запроса. Кнопка с монохромной иконкой и списком в стиле выбора браузера. После закрытия строка и временный выбор сбрасываются.
  • Прямое открытие адресов. Введённые адреса открываются в Linklet, остальные запросы — в выбранном поисковике.
  • Совместимость сайтов. Встроенный браузер сообщает desktop-идентификатор Safari; исправлен упрощённый вид выдачи Google в проверенном сценарии.
  • Подготовлена интеграция Raycast. Исходники команды поиска выделенного текста включены в архив. Команда использует основной поисковик Linklet. Публикация в Raycast Store и проверка в реальных приложениях отложены.
  • Quick Search: a compact translucent input panel opens on a configurable hotkey, without waiting for text selection or the clipboard.
  • Search settings: configure the shortcut and default engine: Google, Yandex, DuckDuckGo, or Bing.
  • Per-query engine selection: monochrome icons and a picker matching the browser selector; closing the panel resets the query and temporary engine.
  • Direct URL opening: entered web addresses open directly in Linklet; other input is searched.
  • Website compatibility: desktop Safari identification improves website compatibility, including the observed simplified Google results view.
  • Raycast integration prepared: source for Search Selected Text is included. It uses Linklet’s default engine. Store publication and real-application testing are deferred.
