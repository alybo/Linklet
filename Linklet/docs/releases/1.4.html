Linklet 1.4

  • Избранные сайты в быстром поиске: добавление, перетаскивание, временное скрытие и открытие через обычный предпросмотр Linklet.
  • Иконки сайтов по запросу: favicon загружается только по явной команде пользователя.
  • Несколько окон предпросмотра: каждая новая входящая ссылка может открываться в отдельном окне.
  • Запоминание расположения окна: размер и позиция сохраняются для каждого сайта, а окно возвращается в видимую область при смене экрана.
  • Управление из Dock: Linklet появляется в Dock при открытых окнах; команда «Закрыть все окна» не завершает приложение.
  • Favorite sites in Quick Search: add, reorder, temporarily hide, and open websites through Linklet’s standard preview flow.
  • On-demand site icons: favicons download only after an explicit user action.
  • Multiple preview windows and per-site remembered window placement.
  • Dock controls: Close All Windows does not quit the app.
