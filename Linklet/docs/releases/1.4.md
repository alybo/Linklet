# Linklet 1.4

## Русский

- **Избранные сайты в быстром поиске.** Добавляйте сайты в Settings → Search,
  меняйте их порядок перетаскиванием и временно скрывайте без удаления. Плитка
  открывает сайт через обычный безопасный сценарий предпросмотра Linklet.
- **Иконки сайтов по запросу.** Для избранного сайта можно явно загрузить favicon;
  Linklet не делает такие сетевые запросы сам по себе.
- **Несколько окон предпросмотра.** В настройках можно включить открытие каждой
  новой входящей ссылки в отдельном окне.
- **Запоминание расположения окна.** Linklet сохраняет размер и позицию окна для
  каждого сайта отдельно и возвращает окно в видимую область, если изменился экран.
- **Управление из Dock.** Когда открыты просмотр или настройки, Linklet появляется
  в Dock; команда «Закрыть все окна» закрывает окна, не завершая приложение.

Требуется macOS 14 или новее. Приложение поддерживает Apple Silicon и Intel.

## English

- **Favorite sites in Quick Search:** add sites in Settings → Search, reorder
  them with drag and drop, and hide them temporarily without deleting them.
  A tile opens the site through Linklet’s standard safe preview flow.
- **On-demand site icons:** a favicon is downloaded only when explicitly requested;
  Linklet never fetches one automatically.
- **Multiple preview windows:** Settings can open each new incoming link in its
  own preview window.
- **Remembered window placement:** Linklet remembers each website’s window size
  and position and keeps restored windows on a visible display.
- **Dock controls:** Linklet appears in the Dock while preview or Settings windows
  are open; Close All Windows closes them without quitting the app.

Requires macOS 14 or later. Supports Apple Silicon and Intel.
