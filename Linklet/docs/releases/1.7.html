Linklet 1.7

Номер сборки / Build: 31.

Русский

Что нового

  • Нативные настройки с пятью понятными разделами, русским и английским языками. Данные сайтов открываются отдельно; раздел поиска и браузеров всегда раскрыт.
  • Первое знакомство с учебным окном, подсказками адресной строки и передачи ссылки другому браузеру. В конце можно открыть быстрый поиск или настройки.
  • Меню строки macOS: быстрый поиск, ссылка из буфера, боковая панель, открытые окна, загрузки, настройки и справка. Значок меню — 16×16 pt.
  • Анимированные папки, плавное раскрытие списков и более ясная иерархия боковой панели. Состояние раскрытия сохраняется; анимации учитывают уменьшение движения.

Исправления

  • Убраны лишние загрузки данных сайтов и сканирования браузеров при переключении разделов настроек; работа с большими списками выполняется без построения всех строк.
  • Исправлены платёжные окна, которые сайт сначала создаёт с пустым адресом.
  • Закрытие страницы из боковой панели оставляет панель открытой. При открытии панели через меню она ждёт первого наведения курсора перед автоскрытием.

Версия также включает подготовленные изменения 1.6: независимые окна сайтов, открытые страницы и загрузки в боковой панели, выбор и перетаскивание файлов, поиск на странице, масштаб, историю и разрешения сайтов, переключение AdGuard для отдельных сайтов.

Приватное хранение остаётся значением по умолчанию; постоянное включается явно. Другому браузеру передаётся исходная входящая ссылка.

Требования: macOS 14 или новее; стеклянная панель — macOS 26 или новее.

English

What's new

  • Native settings with five clear sections, Russian and English interfaces, a separate website-data screen, and fully expanded search and browser settings.
  • First-run walkthrough with an interactive example window, address-bar and external-browser hints, and shortcuts to Quick Search and Settings at the end.
  • macOS menu-bar actions for Quick Search, clipboard links, the sidebar, open windows, downloads, settings and help. The menu icon is 16×16 pt.
  • Animated folder artwork, smooth list expansion, and clearer sidebar indentation. Expansion state persists and animations respect Reduce Motion.

Fixes

  • Avoided unnecessary website-data loads and browser scans when switching settings sections; large website-data lists use lazy rows.
  • Fixed payment windows initially created with an empty URL.
  • Closing a page from the sidebar leaves the sidebar open. Opening it from the menu waits for the pointer to enter before pointer-based auto-hide begins.

Also includes the prepared 1.6 changes: independent website windows, sidebar page and download lists, file selection and drag and drop, find on page, zoom, history, website permissions, and per-site AdGuard controls.

Private website storage remains the default; persistent storage requires an explicit choice. External browsers receive the original incoming URL.

Requirements: macOS 14 or later; glass sidebar styling requires macOS 26 or later.
