## Русский

- **Быстрый поиск в чёлке.** Панель плавно раскрывается у верхнего края экрана при наведении на чёлку или по горячей клавише. В настройках можно выбрать привычное всплывающее окно.
- **Адаптивная ширина.** Компактная панель расширяется при длинном запросе. Оба дизайна используют закладки из общей библиотеки.
- **Выбор поисковика.** Значок в строке открывает меню выбора для текущего запроса. Значок можно скрыть в настройках.

## English

- **Notch Quick Search.** The panel smoothly unfolds from the top of the screen when you hover over the notch or press the shortcut. The classic floating window is available in Settings.
- **Adaptive width.** The compact panel expands as you enter longer queries. Both designs use bookmarks from the same library.
- **Search engine picker.** The icon in the search field opens a menu for the current query. You can hide the icon in Settings.
