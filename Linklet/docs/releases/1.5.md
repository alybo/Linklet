# Linklet 1.5

## Русский

- Исправлено растягивание окна входа длинным адресом авторизации: страница и кнопка браузера остаются в видимой области.
- Исправлена обработка дополнительных окон сайтов: окно входа больше не заменяет исходную страницу. Сохраняются связь с исходным окном, обмен сообщениями, общие данные сессии и закрытие окна самим сайтом. Работает без списка отдельных провайдеров авторизации.
- Добавлена опциональная глобальная панель у левого края любого экрана: закладки, раскрывающиеся папки, поиск ссылок, сворачиваемая история открытий и настройки. Панель вызывается наведением, сочетанием ⌃⌥B или из меню Linklet.
- Единая организация закладок: ссылки и папки перемещаются в общем списке, ссылки можно переносить между папками. В быстром поиске отображаются те же ссылки в общем порядке, без папок.
- Общие автоматически загружаемые иконки сайтов для поиска, панели и истории. Текущую страницу можно добавить кнопкой закладки в окне предпросмотра.
- Полностью чёрная боковая панель с округлёнными плечами, индикатором раскрытия и анимацией. Отступы сверху и снизу — 10% ширины экрана.
- История выключена вместе с панелью по умолчанию и хранится только в текущем запуске. Сохранение между запусками включается отдельно; его выключение удаляет историю с диска. В списке до 200 исходных ссылок, без переадресаций и служебных окон входа.

Некоторые провайдеры, включая Google, могут запрещать вход во встроенном WebKit. В этом случае продолжите вход в выбранном браузере. Linklet передаёт исходную ссылку сайта; аккаунты и cookies других браузеров в Linklet не переносятся.

## English

- Long sign-in URLs no longer stretch popup windows beyond the screen.
- Website popup windows now preserve their opener, messaging, shared session data and script-driven closing instead of replacing the original page. The implementation is independent of the sign-in provider.
- Optional global sidebar at the left edge of each screen with bookmarks, collapsible folders, link search, recent openings and settings. Open it by hovering, pressing ⌃⌥B, or using the Linklet menu.
- Unified bookmarks: reorder folders and links in one list and move links between folders. Quick Search shows the same links in the shared order, with folders omitted.
- Automatically loaded site icons are shared across Quick Search, the sidebar and history. Save the current page using the preview's bookmark button.
- Black sidebar with rounded shoulders, an animated reveal indicator and top/bottom margins equal to 10% of screen width.
- The sidebar is off by default. Recent openings stay in memory unless history saving is explicitly enabled. Turning saving off removes stored history. The list retains up to 200 incoming links and excludes redirects and sign-in windows.

Some providers, including Google, prohibit sign-in inside embedded WebKit. Continue in your chosen browser in that case. Linklet hands off the original site link and does not import browser accounts or cookies.
