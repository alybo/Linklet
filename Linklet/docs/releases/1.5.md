# Linklet 1.5

## Русский

### Что нового

- **Глобальная боковая панель.** Закладки, папки и недавние ссылки доступны у левого края любого экрана. Открывайте панель наведением на край, сочетанием ⌃⌥B или из меню Linklet. Задержка наведения настраивается; ярлык открытия можно включить отдельно.
- **Единая система закладок.** Панель и быстрый поиск используют один список. Перемещайте ссылки и папки, переносите закладки между папками. В быстром поиске отображаются ссылки без папок. Текущую страницу можно сохранить кнопкой закладки в окне предпросмотра.
- **Организация разделов.** «Закладки» и «Недавние» сворачиваются нажатием на заголовок и меняются местами перетаскиванием. Порядок и свёрнутое состояние сохраняются.
- **История с подтверждением очистки.** Сначала видны 10 последних ссылок; «Показать ещё» добавляет следующие 10. Очистка требует подтверждения прямо в панели и допускает отмену. Сохранение истории между запусками включается отдельно; по умолчанию она остаётся только в памяти текущего запуска.
- **Более чёткие и актуальные иконки.** Общие иконки используются в поиске, закладках и истории. Linklet выбирает крупные изображения до 128 пикселей и проверяет их обновление после каждой загрузки страницы.
- **Настраиваемая ширина.** Перетаскивайте правый край панели; при наведении появляется курсор изменения ширины. Ширина сохраняется и ограничена четвертью экрана. Текст и значки учитывают системную настройку размера боковых панелей macOS.
- **Новое оформление и движение.** Чёрный фон, закруглённые плечи у края экрана, белые подписи, компактные кнопки и тонкая серая пунктирная линия при переносе. Плавное раскрытие и закрытие поддерживают смену направления и системное «Уменьшение движения».

### Исправления

- Создание и редактирование папок и закладок происходит внутри панели: окно остаётся у края экрана, доступны сохранение и отмена.
- Обычные ссылки, которые сайт открывает в новой вкладке, переходят в стандартном окне Linklet с навигацией назад.
- Служебные окна авторизации сохраняют исходную страницу, связь с ней, обмен сообщениями и общую сессию. Обработка не привязана к отдельному провайдеру. Длинные адреса входа больше не растягивают окно за пределы экрана.
- Убрано дополнительное затухание панели в конце закрытия; область изменения ширины вынесена в отдельный нативный слой.

Панель выключена по умолчанию и включается в настройках. Некоторые провайдеры, включая Google, ограничивают вход во встроенном WebKit; в таком случае доступно продолжение в выбранном браузере с исходной ссылкой сайта. Поддержка входа ключом доступа с телефона через QR-код в эту версию не включена.

**Требования:** macOS 14 или новее.

## English

### What's new

- **Global sidebar.** Bookmarks, folders and recent links are available at the left edge of any screen. Open it by hovering over the edge, pressing ⌃⌥B or using the Linklet menu. The hover delay is configurable; an optional reveal indicator is available in settings.
- **Unified bookmarks.** The sidebar and Quick Search share one list. Reorder links and folders and move bookmarks between folders. Quick Search shows links without folders. Save the current page with the preview's bookmark button.
- **Organize sections.** Collapse Bookmarks and Recent by clicking their headers, or drag a header to change section order. Both order and collapsed state are saved.
- **History with confirmation before clearing.** Start with the latest 10 links; Show more adds 10 at a time. Clearing requires an inline confirmation with Cancel. Saving history between launches is a separate opt-in; by default it stays in memory for the current launch.
- **Sharper, updated site icons.** Quick Search, bookmarks and history share icons. Linklet selects larger images up to 128 pixels and checks for updates after every page load.
- **Adjustable width.** Drag the sidebar's right edge, where a horizontal resize cursor appears. Width is saved and capped at one quarter of the screen. Text and icons follow the macOS sidebar size preference.
- **Refined appearance and motion.** A black background, rounded shoulders at the screen edge, white labels, compact controls and a thin gray dashed insertion line. Smooth opening and closing support interrupted transitions and macOS Reduce Motion.

### Fixes

- Creating and editing bookmarks and folders happens inside the sidebar, keeping the window anchored to the screen edge with Save and Cancel.
- Ordinary new-tab links navigate in the standard Linklet preview with back history.
- Sign-in popups preserve the original page, opener, messaging and shared session without relying on a list of providers. Long sign-in URLs no longer stretch popup windows offscreen.
- Removed the extra fade at the end of sidebar dismissal and moved the resize target into a separate native layer.

The sidebar is off by default and can be enabled in settings. Some providers, including Google, restrict sign-in inside embedded WebKit; continue in your chosen browser using the original site link when needed. Phone passkey sign-in via QR code is not included in this version.

**Requirements:** macOS 14 or later.
