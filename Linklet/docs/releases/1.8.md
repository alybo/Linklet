# Linklet 1.8

Номер сборки / Build: **42**.

Проверка сборки 42: **188 тестов, 0 ошибок**, обычный Release собран успешно.
Новая карточка проверена в светлом и тёмном оформлении; покрыты нажатие,
отложенное наведение, переход со стрелки в список, закрытие снаружи и клавиатура.
Сохраняются проверки восстановления истории загрузок, страниц по 10, поиска по
скрытым записям и очистки без удаления файла или остановки текущей передачи.
Сборка не содержит пользовательские файлы закладок, истории или cookies;
профиль хранится отдельно от приложения.

## Русский

- Собственная карточка браузеров под стрелкой повторяет материал и скругления
  окна. Подсветка строк монохромная; в списке видны иконки, названия и сочетания
  клавиш. Длинный список прокручивается; доступны ↑/↓, Enter и Esc.
- «Поиск и браузеры» → «Открывать список браузеров»: «По нажатию» (по умолчанию)
  или «По наведению». Открытие при наведении через 180 мс, закрытие через 300 мс
  после ухода из стрелки и карточки. Переход через зазор не закрывает меню;
  клавиатурный выбор удерживает список открытым. Щелчок снаружи закрывает список,
  не блокируя взаимодействие со страницей. Потеря фокуса и закрытие окна отменяют
  отложенное открытие. Режим применяется и к компактной стрелке, и к полной кнопке.

- Общая боковая панель включена в новом профиле и открывается при наведении
  на левый край. Явное отключение в существующем профиле сохраняется.
- По умолчанию справа от адреса остаётся стрелка меню браузеров. В меню входят
  все выбранные браузеры, включая основной; сочетание ⌘1 сохраняется.
- Настройки → «Поиск и браузеры» → «Показывать кнопку “Открыть в браузере”»
  возвращают прежнюю кнопку с названием браузера. Изменение применяется к
  открытым окнам; знакомство показывает выбранный вариант панели.

- История загрузок сохраняется на этом Mac между запусками: последние 200
  записей, показ по 10 с кнопкой «Показать ещё». Активные передачи всегда видны;
  поиск проверяет и записи за пределами текущей страницы.
- «Очистить историю» в загрузках с подтверждением удаляет записи, сохраняя
  скачанные файлы и активные передачи. Незавершённые записи после аварийного
  закрытия отмечаются как прерванные, без автоматического возобновления.

- Размер и положение окна общие для сайта и его поддоменов: переход между
  YouTube и Studio не меняет текущую рамку окна. Старые настройки сохраняются;
  при конфликте используется рамка основного домена или `www`.
- HTML/XHTML-страницы не скачиваются автоматически при отрицательном флаге
  поддержки MIME от WebKit. Явные вложения HTML и обычные загрузки сохраняются.
- Диагностические инспектор, TCP-туннель и изменение поведения потери фокуса
  удалены. Используется обычная передача файлов WebKit.

- Сайты, открытые из других страниц, получают обычное окно. Размер и положение
  восстанавливаются по домену, в том числе после перенаправлений; изменения окна
  сохраняются для следующего открытия. Окно показывается сразу с подготовленным
  размером после первого ответа сайта, без скачка от базового размера; при ошибке
  соединения появляется обычное окно с сообщением об ошибке. Для ссылок Google
  вида `google.com/url?url=…` известный целевой сайт определяется из ссылки:
  сохранённый размер применяется сразу, без ожидания ответа Google. Сам переход
  по исходной ссылке и её передача внешнему браузеру сохраняются.
- Необязательный режим «Разделять по разделам»: четыре самостоятельных ярлычка
  в постоянных местах у левого края экрана открывают окна, закладки, историю
  и загрузки. Каждая панель раскрывается у своего ярлычка и запоминает свою
  ширину. Ширина общей панели хранится отдельно.
- Необязательный поиск появляется сверху панели при начале печати, включая
  открытие наведением без переключения активного приложения. Escape убирает
  поиск, повторный Escape закрывает панель. Ищет названия и адреса страниц, закладки внутри
  папок, вся доступная история и имена загрузок. В раздельном режиме поиск
  относится к выбранному разделу.
- «Восстановить закрытое окно» в контекстном меню раздела открытых окон.
  До двадцати последних закрытых страниц доступны в текущем сеансе.
- Белые монохромные иконки распространённых типов файлов и базовая иконка
  неизвестного типа. Для загрузок доступны «Показать в Finder» и копирование
  исходной HTTP(S)-ссылки, когда она предоставлена загрузкой.

Раздельные панели и поиск по умолчанию выключены. Существующие настройки общей
панели сохраняются. Приватное хранение данных сайтов остаётся значением по
умолчанию; другому браузеру передаётся исходная входящая ссылка.

## English

- A custom browser card below the arrow matches the window material and corners,
  with monochrome row highlights, icons, names and shortcuts. Long lists scroll;
  arrow keys, Return and Escape work without moving focus away from the page.
- Search & Browsers → Open browser list offers On click (default) or On hover.
  Hover opens after 180 ms and closes 300 ms after leaving both the arrow and card;
  moving across the gap keeps it open. Keyboard selection pins the card. Outside
  clicks dismiss it and continue to the page; focus loss and closing cancel delayed
  presentation. Both compact and full toolbar modes use the same card.

- The combined sidebar is enabled in a fresh profile and opens at the left edge.
  Existing explicit opt-outs are preserved.
- The toolbar defaults to an arrow beside the address for the browser menu.
  All selected browsers, including the primary browser, appear in the menu;
  ⌘1 remains available.
- Settings → Search & Browsers → Show Open in browser button restores the
  named button. Open windows and onboarding reflect the selected toolbar style.

- Download history persists locally across launches: the latest 200 records,
  shown in batches of 10 with Show more. Active transfers remain visible and
  search includes records beyond the current page.
- Clear history asks for confirmation and removes records while keeping saved
  files and active transfers. Unfinished records after an unclean shutdown
  appear as interrupted; they are not automatically resumed.

- Window geometry is shared across a site's subdomains, preserving the current
  frame when moving between YouTube and Studio. Existing root/www preferences
  take priority over conflicting legacy subdomain frames.
- HTML/XHTML documents remain pages even if WebKit's MIME capability flag is
  false; explicit HTML attachments and ordinary file downloads are preserved.
- Removed the diagnostic inspector, TCP tunnel and diagnostic focus behavior.
  File uploads use the standard WebKit path.

- Site-created windows use a normal initial size and restore saved size and
  position for the destination host, including after redirects. The first response
  prepares the frame before the window is shown, eliminating the initial resize
  flash; connection failures still display a normal error window. Google Search
  `/url?url=…` links with a saved destination frame open immediately using that
  frame, without waiting for Google. WebKit and browser handoff retain the
  original incoming URL.
- Optional separate sections: four fixed edge tabs open windows, bookmarks,
  history and downloads near their own anchors, each remembering its own width.
  The combined sidebar keeps its independent width.
- Optional sidebar search appears when typing starts, including after a hover
  reveal without activating Linklet. Escape dismisses search; a second Escape
  closes the panel. It filters page names and addresses, bookmarks inside
  folders, all available history and download filenames. Separate panels search
  their selected section.
- Restore closed window from the open-windows section context menu. Up to twenty
  closed pages remain available during the current session.
- White monochrome file-type icons with a generic fallback, Show in Finder and
  copying a download's original HTTP(S) link when supplied by the transfer.

Separate panels and sidebar search are off by default. Existing sidebar
preferences, private website storage defaults and original-URL browser handoff
are preserved.

## Поисковые переходы / Search-result destinations

- Быстрое определение адреса из известных форматов Google, Bing (`u=a1…`),
  DuckDuckGo (`uddg`), Yahoo (`RU=`) и прозрачных ссылок Яндекса.
- Прямые ссылки из Google, Bing, DuckDuckGo, Яндекса, Yahoo, Brave, Ecosia и
  Startpage также открывают знакомый сайт сразу с его размером и положением.
- Вложенные обёртки разбираются не более четырёх раз. Неоднозначные, повреждённые
  и непрозрачные ссылки ждут ответа WebKit; исходный переход не переписывается.
- Промежуточная JS-страница Bing не подменяет сохранённую геометрию сайта.

## Диагностическая сборка 37 / Diagnostic build 37

Сборка с явным флагом `LINKLET_WEB_INSPECTOR` включает Web Inspector в основных
и дочерних веб-окнах. В обычной сборке этот код выключен. Инспектор предназначен
для получения ошибок JavaScript и состояния сетевых запросов при повторении
зависания загрузки YouTube; исправление самой загрузки пока не заявляется.
Диагностическая сборка сохраняет веб-окна при переключении в другое приложение.

## Проверочный TCP-транспорт, сборка 38

Дополнительный флаг `LINKLET_TCP_UPLOAD_DIAGNOSTICS` направляет только
`upload.youtube.com:443` через локальный CONNECT-туннель для проверки обрывов
QUIC в системном WebKit. TLS остаётся между WebKit и YouTube. Системные настройки
сети не меняются; режим действует в памяти этого процесса. Обычные сборки
не включают этот транспорт. Владелец подтвердил, что реальная загрузка в этом
режиме идёт. В Safari тот же файл также зависает; журнал Safari повторяет
ошибку QUIC и потерю соединения. Первопричина ещё исследуется, окончательное
исправление штатной загрузки не заявляется.
