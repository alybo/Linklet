# Linklet 1.8

Номер сборки / Build: **34**.

## Русский

- Сайты, открытые из других страниц, получают обычное окно. Размер и положение
  восстанавливаются по домену, в том числе после перенаправлений; изменения окна
  сохраняются для следующего открытия. Окно показывается сразу с подготовленным
  размером после первого ответа сайта, без скачка от базового размера; при ошибке
  соединения появляется обычное окно с сообщением об ошибке.
- Необязательный режим «Разделять по разделам»: четыре самостоятельных ярлычка
  в постоянных местах у левого края экрана открывают окна, закладки, историю
  и загрузки. Каждая панель раскрывается у своего ярлычка и запоминает свою
  ширину. Ширина общей панели хранится отдельно.
- Необязательный поиск появляется сверху панели при начале печати, включая
  открытие наведением без переключения активного приложения. Escape убирает
  поиск, повторный Escape закрывает панель. Ищет названия и адреса страниц, закладки внутри
  папок, вся доступная история и имена загрузок. В раздельном режиме поиск
  относится к выбранному разделу.
- «Восстановить закрытое окно» в контекстном меню раздела открытых окон.
  До двадцати последних закрытых страниц доступны в текущем сеансе.
- Белые монохромные иконки распространённых типов файлов и базовая иконка
  неизвестного типа. Для загрузок доступны «Показать в Finder» и копирование
  исходной HTTP(S)-ссылки, когда она предоставлена загрузкой.

Раздельные панели и поиск по умолчанию выключены. Существующие настройки общей
панели сохраняются. Приватное хранение данных сайтов остаётся значением по
умолчанию; другому браузеру передаётся исходная входящая ссылка.

## English

- Site-created windows use a normal initial size and restore saved size and
  position for the destination host, including after redirects. The first response
  prepares the frame before the window is shown, eliminating the initial resize
  flash; connection failures still display a normal error window.
- Optional separate sections: four fixed edge tabs open windows, bookmarks,
  history and downloads near their own anchors, each remembering its own width.
  The combined sidebar keeps its independent width.
- Optional sidebar search appears when typing starts, including after a hover
  reveal without activating Linklet. Escape dismisses search; a second Escape
  closes the panel. It filters page names and addresses, bookmarks inside
  folders, all available history and download filenames. Separate panels search
  their selected section.
- Restore closed window from the open-windows section context menu. Up to twenty
  closed pages remain available during the current session.
- White monochrome file-type icons with a generic fallback, Show in Finder and
  copying a download's original HTTP(S) link when supplied by the transfer.

Separate panels and sidebar search are off by default. Existing sidebar
preferences, private website storage defaults and original-URL browser handoff
are preserved.
