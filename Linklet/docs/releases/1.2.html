Linklet 1.2

Что нового

  • Четыре раздела настроек с боковой навигацией.
  • Необязательное сохранение входа в аккаунты и настроек сайтов на этом Mac. Объяснение режимов при первом открытии ссылки.
  • Удаление данных отдельных сайтов или всех сайтов; очистка после 7, 30 или 90 дней без посещений.
  • Ручной порядок браузеров перетаскиванием при выключенной сортировке по использованию.
  • Раздел «О программе», ссылки разработчика и окно благодарности.

Изменения

Без сохранения данные удаляются при закрытии или скрытии окна просмотра. Для сохранения авторизации включите «Сохранять данные сайтов».

Начиная с 1.2 скачивание и установка обновлений требуют подтверждения. Само обновление с 0.1.1 выполняется по настройкам старой версии.

Новые номера версий состоят из двух частей: 1.2, 1.3 и далее. Требуется macOS 14 или новее.

What's new

  • Four settings pages with sidebar navigation.
  • Optional local persistence for website sign-ins and preferences, with a first-link introduction.
  • Delete individual sites or all website data; expire data after 7, 30, or 90 days without a visit.
  • Drag to set browser priority when usage sorting is off.
  • About page, developer links, and a support sheet.

Without saving, website data is deleted when the preview closes or hides. Enable Save Website Data to retain sign-ins.

Starting with 1.2, update downloads and installation require confirmation. Updating from 0.1.1 follows the old version's saved preferences.

Version numbers now use two components: 1.2, 1.3, and so on. Requires macOS 14 or later.
