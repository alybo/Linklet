# Linklet 1.6

Номер сборки / Build: **21**.

## Русский

### Что нового

- **Независимые окна сайтов.** Основные окна и окна, созданные страницами, используют единое оформление и перемещаются независимо. Окна авторизации сохраняют связь с исходной страницей, обмен сообщениями и общую сессию сайта; закрытие исходного окна не закрывает остальные страницы.
- **Адрес и действия страницы.** Домен раскрывается в редактируемый адрес по нажатию или ⌘L. В поле можно ввести ссылку или запрос для выбранного поисковика. Значки копирования и избранного появляются слева от адреса при наведении на верхнюю панель. Копирование левой или правой кнопкой показывает галочку на две секунды; сохранённая закладка обозначается заполненным значком.
- **Открытые окна в боковой панели.** Раздел показывает текущие страницы и позволяет вернуться в любое окно без повторной загрузки. При наведении на строку доступен крестик закрытия конкретного окна.
- **Загрузки и выбор файлов.** Файлы, изображения и ссылки можно сохранять средствами WebKit; в боковой панели видны ход и результат загрузок. Поддержаны нативный выбор файлов для отправки на сайт и перетаскивание файлов в страницу.
- **Поиск на странице.** ⌘F открывает компактную плавающую панель. Найденный текст выделяется акцентным цветом macOS с анимацией границы выделения. Подсветка следует за текстом при прокрутке и изменении содержимого страницы.
- **Обновление и масштаб.** ⌘R обновляет страницу; ⌘+, ⌘− и ⌘0 увеличивают, уменьшают и сбрасывают масштаб. Дополнительная кнопка обновления не занимает место в панели окна.
- **История последних страниц.** Учитываются перенаправления и переходы внутри сайта. Закрытая страница перемещается в начало истории и открывается по последнему адресу с сохранённой позицией прокрутки. Сохранение истории между запусками остаётся отдельной настройкой.
- **Разрешения сайтов.** Добавлены запросы доступа к камере, микрофону и геолокации с отдельным согласием для сайта и разрешением macOS. Доступом можно управлять в настройках данных сайтов; геолокация использует нативный Core Location.
- **AdGuard для отдельных сайтов.** Блокировку можно переключать в контекстном меню страницы. После изменения страница обновляется автоматически.
- **Обновлённая боковая панель.** Компактные заголовки разделов с иконками, кнопки заголовков при наведении, единые стрелки папок и разделов. Состояние раскрытия папок сохраняется после перезапуска независимо от истории. Доступны экспериментальное стеклянное оформление на macOS 26+ и отключение панели поверх полноэкранных приложений.

### Исправления

- Устранена зависимость перемещения служебных окон от основного окна; сохранены связи авторизации между страницами.
- Исправлены залипание курсора после ввода текста и работы с картами, скачивание изображений из контекстного меню, смещение и краткое нативное мерцание поисковой подсветки.
- Унифицированы отступы, размеры областей нажатия и мягкая подсветка элементов адресной панели.
- Сохранён идентификатор приложения `Linklet`, используемый существующими настройками.

Приватный просмотр остаётся режимом по умолчанию. Связанные окна сайта используют общую временную сессию, которая очищается после закрытия последнего связанного окна; постоянное хранение включается пользователем. При открытии во внешнем браузере передаётся исходная входящая ссылка. Некоторые сайты ограничивают авторизацию во встроенном WebKit — в таком случае доступно продолжение во внешнем браузере.

**Требования:** macOS 14 или новее. Стеклянное оформление боковой панели требует macOS 26 или новее.

## English

### What's new

- **Independent website windows.** Incoming pages and site-created windows share the same chrome and move independently. Sign-in windows retain opener messaging and the shared website session. Closing the original window leaves other pages open.
- **Address and page actions.** Click the domain or press ⌘L to edit the URL or enter a query for the selected search engine. Copy and bookmark icons appear to the left of the address when hovering over the toolbar. Left- or right-clicking Copy shows a checkmark for two seconds; a filled bookmark indicates a saved page.
- **Open windows in the sidebar.** Switch to an existing page without reloading it, or hover over its row to close that window.
- **Downloads and file selection.** Save files, images and links through WebKit and follow their progress in the sidebar. Websites support native file selection and file drag and drop.
- **Find on page.** ⌘F opens a compact floating panel. Animated highlights use the macOS accent color and remain anchored during scrolling and page layout changes.
- **Reload and zoom.** ⌘R reloads the page; ⌘+, ⌘− and ⌘0 increase, decrease and reset page zoom without adding a reload button to the toolbar.
- **History of visited pages.** Redirects and in-site navigation update history. Closing a window brings its last page to the top; reopening restores its last URL and saved scroll position. Saving history between launches remains a separate opt-in.
- **Website permissions.** Camera, microphone and geolocation requests use per-site consent alongside macOS permission checks. Manage access in website-data settings; location delivery uses native Core Location.
- **Per-site AdGuard.** Toggle content blocking from the page context menu; changes reload the page automatically.
- **Refined sidebar.** Compact section headings with icons, hover actions and matching folder/section disclosure arrows. Folder expansion survives relaunch independently of browsing history. Optional experimental glass styling is available on macOS 26+, alongside a setting to suppress the sidebar over full-screen applications.

### Fixes

- Removed parent-window movement coupling while preserving communication between sign-in pages.
- Fixed stuck cursors after text input or map dragging, context-menu image downloads, and misplaced or briefly flashing native find highlights.
- Unified toolbar spacing, hit targets and subtle hover backgrounds.
- Preserved the `Linklet` application identifier used by existing preferences.

Private browsing remains the default. Related website windows share temporary data until the last related window closes; persistent storage requires an explicit choice. Opening a page in an external browser sends the original incoming URL. Some websites restrict embedded WebKit sign-in; continue in the external browser when needed.

**Requirements:** macOS 14 or later. Glass sidebar styling requires macOS 26 or later.
