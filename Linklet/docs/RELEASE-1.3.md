# Выпуск Linklet 1.3 — сборка 4

Исходный код фиксируется тегом `v1.3`. Выпуск продолжает bundle identifier `Linklet`, существующую Apple Developer Team и ключ Sparkle; публичная лента остаётся на 1.2 до готовности подписанного выпуска.

## Изменения

Быстрая строка поиска по настраиваемой глобальной клавише, раздел Search, выбор поисковика на один запрос, прямое открытие адресов, desktop Safari user agent. Встроенное чтение выделения отложено. Исходники необязательного расширения Raycast находятся в `integrations/raycast-linklet`; расширение собрано и проверено статически, пользовательское тестирование и публикация в Store отложены.

## Перед публикацией

1. Собрать Release из `v1.3` для arm64 и x86_64. Сохранить номер 1.3 / 4 и bundle identifier `Linklet`.
2. Подписать приложение прежним Developer ID Application. Нотарифицировать и прикрепить ticket. Проверить вложенные компоненты Sparkle. Debug-entitlement `disable-library-validation` не включать.
3. Подписать и нотарифицировать финальный `Linklet-1.3.dmg`, прикрепить ticket.
4. Если в черновике находится локальный ad-hoc DMG, заменить его подписанным файлом. Локальный образ — только проверка сборки, не готовый публичный релиз.
5. Подготовить соответствующие исходники с точными зависимостями. Архив содержит `vendor/` и инструкции `SOURCE-BUILD.md`.
6. Запустить `scripts/prepare-sparkle-update.sh` с финальным DMG, исходниками и Sparkle tools. Использовать существующий ключ издателя.
7. Проверить установку и обновление 1.2 → 1.3, глобальную клавишу без Accessibility-доступа, прямые адреса и четыре поисковика. Тестирование расширения Raycast в этой итерации отложено по решению владельца.
8. В релизе оставить ровно `Linklet-1.3.dmg` и `Linklet-1.3-source.tar.gz`, обновить SHA-256 в описании, опубликовать релиз. Затем публиковать appcast — последним.

На Mac подготовки нет Developer ID Application: только Apple Development. Подписывать публичный релиз этим сертификатом или ad-hoc подписью нельзя под видом готового нотарифицированного выпуска.
