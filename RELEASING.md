# Выпуск Linklet

Публичные исходники и готовые выпуски: https://github.com/alybo/Linklet.
Совместная разработка ведётся в том же публичном репозитории. Linklet-dev больше не используется для текущей работы.

## Что получает пользователь

В GitHub Releases для каждой версии:

- `Linklet-VERSION.dmg` или `.zip` — подписанное и нотарифицированное приложение.
- `Linklet-VERSION-source.tar.gz` — соответствующие исходники этой сборки, включая необходимые сторонние зависимости и инструкции сборки.
- `SHA256SUMS.txt` — контрольные суммы файлов.
- Описание изменений, требования macOS и ссылка на исходники.

Автоматический архив Source code от GitHub не включает скачиваемые Swift-пакеты. Он не заменяет полный архив соответствующих исходников.

## Порядок выпуска

1. Установить версию и возрастающий номер сборки; проверить тесты.
2. Опубликовать согласованный исходный код под GPL-3.0-only, сохранить сторонние лицензии и установить тег версии. Не включать ключи, сертификаты и личные настройки.
3. Компаньон собирает именно этот код, подписывает Developer ID Application, выполняет notarization и stapling. Подробности — в Linklet/docs/SIGNING-HANDOFF.md.
4. Подготовить соответствующие исходники: код приложения, файлы проекта, ресурсы, необходимые скрипты сборки и точные версии зависимостей из Package.resolved вместе с их лицензиями. Проверить, что архив позволяет собрать эту версию; документировать настройку локальных зависимостей. Проверить также транзитивные зависимости. Не включать ключи подписи издателя.
5. Проверить подпись и установку скачанного приложения. Создать черновик Release с приложением и исходниками. Опубликовать оба одновременно. Хранить исходники доступными всё время распространения бинарника.
6. После интеграции Sparkle подписать финальный архив ключом Sparkle, проверить обновление с предыдущего выпуска и опубликовать appcast последним. Не менять уже подписанные архивы.
